Git / GitHub

1. Configuración inicial

(Solo una vez por equipo/usuario)

git config --global user.name "Tu Nombre"
git config --global user.email "tu@email.com"

2. Clonar un repositorio

git clone https://github.com/usuario/repositorio.git
cd repositorio

3. Flujo básico

# ver qué archivos cambiaron
git status

# agregar todos los cambios
git add .

# o agregar uno específico
git add archivo.txt

# guardar cambios con descripción
git commit -m "mensaje"

# subir cambios a GitHub
git push origin main

4. Trabajar con ramas

# ver ramas locales
git branch

# ver todas (locales y remotas)
git branch -a

# crear rama y cambiarse a ella
git checkout -b mi-rama

# alternativa moderna (mismo efecto)
git switch -c mi-rama
# cambiar a otra rama
git switch main

# borrar rama local (ya mergeada)
git branch -d mi-rama

# subir rama al remoto
git push origin mi-rama

5. Traer cambios

# traer y fusionar cambios
git pull origin main

# solo traer sin fusionar
git fetch

6. Flujo Típico Colaborativo

# 1. Actualizar main
git switch main
git pull origin main

# 2. Crear rama para tu tarea
git switch -c feature/login

# 3. Trabajar, agregar y commitear
git add .
git commit -m "agrego formulario de login"

# 4. Subir tu rama
git push origin feature/login

# 5. En GitHub → abrir Pull Request (PR) y pedir revisión

# 6. Cuando se mergea, actualizar main y borrar rama local
git switch main
git pull origin main
git branch -d feature/login

7. Emergencia

# ver historial resumido
git log --oneline

# ver cambios sin agregar
git diff

# descartar cambios de un archivo
git restore archivo.txt

# quitar del staging (des-hacer git add)
git reset HEAD archivo.txt
